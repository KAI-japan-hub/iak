    iak#

    iak は、ls コマンドをより見やすくしたファイル一覧表示ツールです。 ファイルの種類ごとに色分けして表示し、用途に応じた並べ替えや詳細情報の表示を簡単に切り替えられます。

    主な特徴#

    • ファイルの種類（ディレクトリ／Markdown／PDF／Rust／TOMLなど）ごとに色分けして表示
    • 名前・サイズ・更新日時でソート順を切り替え可能
    • -l オプションでパーミッションやリンク数などの詳細情報を表示
    • --new-mark で24時間以内に更新されたファイルに★マークを表示
    • --tagline / --pdf-title でREADMEやPDFの中身を直接抽出して表示
    • .gitignore を尊重してファイルを除外する --respect-ignore
    • bash / zsh / fish / elvish / PowerShell 向けの補完ファイルを自動生成

    使い方#

    iak [OPTIONS] [FILE]

    FILE を指定しない場合は、現在のディレクトリの内容を表示します。

    オプション#

    • --sort <key> : name / size / mtime の順で並べ替えて表示します。
    • -l, --long : パーミッション・リンク数・所有者情報を表示します。
    • --humanize : ファイルサイズをK/M単位の読みやすい形式で表示します。
    • --new-mark : 24時間以内に更新されたファイルに★を付けます。
    • --respect-ignore : .gitignore のルールを尊重して表示から除外します。

    こんな人におすすめ#

    • ls の表示をもっと見やすくしたい人
    • ファイル一覧をサイズや更新日で並べ替えたい人
    • READMEやPDFの中身をコマンドラインからサッと確認したい人

    例#

    iak --sort size
iak -l --new-mark /path/to/directory
iak --tagline
