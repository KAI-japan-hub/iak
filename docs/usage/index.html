    使い方#

    基本の使い方#

    引数を指定しない場合、カレントディレクトリの中身を一覧表示します。

    iak

    パスを指定すると、そのディレクトリ（またはファイル）を対象にします。

    iak ~/Documents

    よく使うオプション#

    オプション 説明
    -l, --long パーミッション・リンク数・所有者情報などの詳細を表示
    --sort <key> name / size / mtime でソート順を指定
    --humanize ファイルサイズを K / M 単位の読みやすい形式で表示
    --new-mark 24時間以内に更新されたファイルに ★ マークを付ける
    --tagline 対象ディレクトリの README.md から概要を抽出して表示
    --pdf-title 対象の PDF ファイルからタイトルを抽出して表示
    --respect-ignore .gitignore のルールを尊重してファイルを除外

    実行例#

    $ iak --sort size
         1B 2026-07-09 14:12  testdata
        19B 2026-07-09 14:12  .gitignore
        96B 2026-07-09 14:12  tests
       256B 2026-07-09 14:12  src
    $ iak --tagline
A color-coded ls for clearer file display.

    シェル補完#

    bash / zsh / fish / elvish / PowerShell 向けの補完スクリプトを生成できます。

    iak --completions ./completions
